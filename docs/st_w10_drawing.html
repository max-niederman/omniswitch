NOTES

  1. All dimensions mm, nominal — geometry is the FEMM-verified design record, not toleranced for manufacture. Part is axisymmetric about ℄; axial features symmetric about z=0 except Hall sensor and cap details.
  2. Hard envelope constraints: OD ≤ 16.0 (at limit — no paint/coating allowance on shell OD); overall length ≤ 35.0 (28.0 nominal leaves margin). 19.05 mm key pitch → 3.05 mm gap between adjacent units.
  3. Mover: magnet + key attachment only. Travel ±2.5 from shown mid-stroke position = 5.0 full-force stroke. Magnet is axially magnetized; drawn with N toward +z, but see note 10. Keycap stem attachment TBD — the stem is drawn illustratively, its width is not a dimension.
  4. Coil ID is a hard floor: bobbin/guide must keep winding rin ≥ 4.75 (Ø9.50). If the bobbin wall pushes rin above 4.75, winding numbers must be re-run (DESIGN.md open item 2). Guide bore must clear the Ø8.00 magnet over the full ±2.5 travel with low friction (PTFE/POM running surface).
  5. Shell: plain closed tube, 1.0 wall. Do NOT slit (evaluated and rejected — see DESIGN.md §"Shell slit"). Low-carbon magnetic steel (1018/mild); DOM tube preferred, never roll-formed open-seam as the OD-setting part. The shell is the flux return, the magnetic shield, and the housing.
  6. End caps: polymer (material spec open), assumed ≤1.0 axial each to stay inside the 28.0 envelope; geometry not yet designed. Drawn as full-Ø16 discs butted to the shell end faces for envelope accounting only — attachment (bore plug / adhesive / snap) and the top-cap stem clearance bore are undesigned. Steel caps would add shielding but also cogging — simulate before substituting.
  7. Coil polarity: lo coil NI = −300 A·t, hi coil NI = +300 A·t at rated drive s=1 (opposed). One continuous wire; phase reversal at the inter-coil gap.
  8. At full +2.5 travel the magnet top face reaches z = +8.5, leaving 4.5 to the shell end (z = +13) for stem/guide features inside the bore.
  9. Hall sensor: z ≈ −9.5 is the sensing element location (FEMM field-evaluation point of the crosstalk study — not yet simulated in this shell), on axis, in bore. Only 1.0 exists between it and the magnet swept envelope (z = −8.5): the entire sensor package + its carrier from the bottom-cap region must stay below z = −8.5, or interfere with the mover. Carrier not yet designed.
  10. Row-stripe polarity: this sheet draws N toward +z (keycap). In the keyboard, alternate rows are assembled magnet-flipped (mandatory per DESIGN.md; checkerboard explicitly forbidden). Units are otherwise identical hardware.
  11. Not yet designed — model as placeholders, do not scale off this sheet: bobbin (split of the 4.00–4.75 band into running clearance / guide wall / bobbin, and any flanges in the 0.5 coil-to-shell-end margins); end caps; keycap stem, travel stops and rest position (stops must not encroach on the ±2.5 full-force stroke); coil + Hall lead exit (prefer through/around the caps — any shell penetration must re-check shielding, cf. the rejected slit study); keyboard mounting interface; magnet coating allowance (Ø8.00 is the bare FEMM model diameter — resolve at vendor quote).
